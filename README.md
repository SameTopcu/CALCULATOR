# Calculator Application

This project is a simple Android calculator app. The application supports basic arithmetic operations (addition, subtraction, multiplication, division) and has a user-friendly interface.

## Features

- **Basic Operations**: Addition, subtraction, multiplication, and division.
- **Clear Buttons**: `AC` resets the entire calculation, and `C` deletes the last character.
- **Real-time Calculation**: You can see the result of operations in real-time without pressing the equals (`=`) button.
- **Parentheses Support**: You can add parentheses for complex mathematical expressions.

## Installation

To run the project locally, follow these steps:

1. **Clone the Repository**:
    ```bash
    git clone https://github.com/username/calculator-app.git
    ```

2. **Open in Android Studio**:
   Open the project folder in Android Studio.

3. **Install Dependencies**:
   Once the project is opened, Android Studio will automatically install the necessary dependencies.

4. **Run the App**:
   Click on the "Run" button to launch the app on your device or emulator.

## Usage

1. **Select Numbers and Operators**: Choose the numbers and operation (`+`, `-`, `*`, `/`) you want to perform.
2. **View the Result**: The result is displayed in real-time after each operation.
3. **Clear the Input**: Use `C` to delete the last entry or `AC` to reset the entire calculation.
